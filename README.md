# LamGo — Deep Sea Project Showcase

A refined Gradio presentation website for the LamGo travel-discovery project.

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

The supplied LamGo logo is stored at `assets/lamgo_logo.png` and embedded automatically by the app.

The website uses a deep-sea visual system, responsive layouts, subtle motion, and custom line-art SVG icons. The project information follows the supplied source code.
